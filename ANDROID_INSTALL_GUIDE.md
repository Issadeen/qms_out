## 📱 Installation Steps:

### Step 1: Access the App
1. **Make sure your Android device is connected to the same WiFi network as this computer**
2. **Open Chrome browser on your Android device**
3. **Navigate to:** `http://192.168.8.45:3000`

### Step 2: Install as PWA App
1. **Once the app loads**, you'll see the KPC QMS interface with the crimson red theme
2. **Tap the menu (⋮)** in Chrome (top-right corner)
3. **Select "Add to Home screen"** or **"Install app"**
4. **Confirm the installation** when prompted
5. **The app icon will appear on your home screen**

## 🛠 Troubleshooting:

### App Won't Load:
- Ensure both devices are on the same WiFi
- Try refreshing the page
- Check if server is still running (should show "Serving!" message)

### Installation Option Not Available:
- Make sure you're using Chrome browser
- Refresh the page and wait for full load
- Look for "Add to Home screen" in Chrome menu

### App Running Slow:
- Close other browser tabs
- Restart the Chrome browser
- Clear browser cache if needed

## 🔄 Updating the App:
- When you make changes to the code, rebuild with: `npx expo export --platform web`
- Restart the server: `npx serve dist -l 3000`
- Refresh the app on your device
